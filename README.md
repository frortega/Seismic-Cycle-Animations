# Seismic Cycle Animations
Animations related to the seismic cycle for teaching and outreach.

Each animation lives in its own folder with its own `README.md`, and a `REFERENCES.md`
when it relies on third-party data or code sources.

- [Seismic-Cycle/](Seismic-Cycle): Animation explaining a simplified Seismic Cycle model in Subduction Zones. Available in english and spanish.
